# GitHub, integridad académica y uso responsable de IA

## Flujo de trabajo

Crea un Issue por objetivo técnico con hipótesis, criterios de aceptación y evidencia esperada. Trabaja en una rama del repositorio del equipo. Abre un PR que enlace el Issue, el comando de verificación, las métricas y limitaciones. Revisa cambios entre pares y enlaza la evidencia con un commit estable. Mantén en el repositorio docente las guías y ejemplos independientes.

## Integridad académica

Atribuye fuentes, código, modelos y datos. Registra autores y contribuciones. Conserva muestras originales, informes y configuraciones. Distingue resultados reales, simulados y estimados. Si un experimento falla o no se puede ejecutar, documenta el motivo, la evidencia disponible y la próxima prueba.

## Uso de IA

Declara la herramienta y su aporte cuando incida en el código, el análisis o la documentación. Comprueba las salidas con pruebas y fuentes originales. Usa datos sintéticos o anonimizados en los experimentos y evita subir credenciales, registros de usuarios o datos sensibles de Wellness. Verifica licencias y elimina identificadores privados antes de publicar perfiles o trazas.
