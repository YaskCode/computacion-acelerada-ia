# Plataforma Inteligente Wellness 2.0 Escalable

**Entrega:** 01/12/2026 · **Peso:** 45 %.

Evoluciona un componente existente de Wellness 2.0 desde su línea base hasta un servicio de IA optimizado e integrado. Sustenta qué mejora, bajo qué condiciones y qué falta para operar en producción.

| Asignatura | Aporte al proyecto |
|---|---|
| [Ingeniería de Software y Bases de Datos](https://github.com/YaskCode/ing-sofware-y-base-datos) | Plataforma de gestión, arquitectura, microservicios, infraestructura cloud, datos y primer agente |
| [Sistemas Inteligentes](https://github.com/YaskCode/sistemas-inteligentes) | Wellness 2.0 con conocimiento especializado, RAG, agentes y orquestación |
| Computación Acelerada para Inteligencia Artificial | Caracterización de cargas, ejecución y optimización, serving, observabilidad y escalado |

## Entrega integrada

1. Enlaza el repositorio del equipo en [YaskCode-laboratory](https://github.com/YaskCode-laboratory), el commit evaluable y las evidencias de los tres sprints.
2. Documenta arquitectura inicial y final, contrato del servicio, configuración del entorno y comandos para reproducir la ejecución.
3. Presenta el benchmark con muestras, validación de calidad y comparación frente a la línea base. Separa el componente acelerado del tiempo extremo a extremo de Wellness.
4. Demuestra el recorrido desde Wellness hasta el servicio y documenta pruebas de carga, telemetría, estrategia de escalado y reversión.
5. Adjunta análisis de costos y limitaciones. Clasifica cada capacidad como verificada, estimada o pendiente y especifica el entorno.
