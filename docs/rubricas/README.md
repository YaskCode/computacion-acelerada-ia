# Rúbricas propuestas

Los puntos distribuyen el peso de cada actividad del [plan de evaluación del curso](../programa/syllabus.md). Para cada criterio aplica un nivel de 0 a 4 y multiplica el máximo del criterio por el nivel dividido entre 4.

| Nivel | Descriptor |
|---:|---|
| 4 | Cubre los elementos del criterio con evidencia trazable, coherente y verificable |
| 3 | Cubre el resultado principal con evidencia verificable y omisiones menores |
| 2 | Aporta evidencia parcial, con omisiones que limitan la reproducción o interpretación |
| 1 | Presenta una descripción o intento con evidencia insuficiente |
| 0 | Evidencia ausente |

| Actividad | Criterios y máximos | Total |
|---|---|---:|
| Sprint 1 | Carga y diseño de infraestructura (5), entorno e implementación reproducibles (5), evaluación inicial y límites (5) | 15 |
| Sprint 2 | Baseline y diagnóstico (5), estrategia y evidencia de optimización (5), benchmark y control de calidad (5) | 15 |
| Sprint 3 | Arquitectura y escalado (5), servicio e integración (5), carga, observabilidad y costos (5) | 15 |
| Proyecto final | Arquitectura y continuidad (9), integración y reproducción (13,5), evidencia experimental y calidad (13,5), escalabilidad, observabilidad y costos (9) | 45 |
| Asistencia y participación | Asistencia registrada (5), aportes y discusión (5) | 10 |

Valora las limitaciones con su evidencia y el alcance realmente verificado. Una mejora negativa o nula es interpretable si el método y los controles la sustentan. En el proyecto final se evalúa la integración de resultados y decisiones.
