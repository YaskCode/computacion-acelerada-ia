# Sprint técnico 3 · Escalabilidad y despliegue para producción

**Entrega:** 24/11/2026 · **Peso:** 15 %.

Diseña e implementa el despliegue del servicio de inferencia y su integración con Wellness 2.0. Define contrato, infraestructura, señal y límites de escalado, telemetría y costo esperado.

- **Arquitectura de producción.** Diagrama, estrategia de serving, escalabilidad y flujo de integración.
- **Implementación.** Servicio desplegado en el entorno declarado, endpoint funcional, integración y configuración reproducible. Automatiza el despliegue cuando sea pertinente. Si el acceso cloud está bloqueado, registra la ejecución local y las verificaciones cloud pendientes.
- **Evaluación.** Prueba integral y de carga, latencia, throughput, utilización, observabilidad, evidencia de escalabilidad cuando se mida, estimación trazable de costos y limitaciones.
